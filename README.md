# Number-Guessing-Game
 
🎯 Number Guessing Game

A simple Number Guessing Game built using HTML, CSS, and JavaScript.
The game generates a random number and challenges the user to guess it with the help of hints until the correct number is found.

This project demonstrates basic JavaScript logic, DOM manipulation, and user interaction.

🚀 Features

Random number generation

User input using prompts

Hint system (higher / lower)

Attempt counter

Option to quit the game

Play again functionality

Simple and responsive interface

🛠️ Technologies Used

HTML5 – Structure of the web page

CSS3 – Basic styling and layout

JavaScript (Vanilla JS) – Game logic and interaction

🎮 How the Game Works

The user enters the maximum number for the range.

The program generates a random number between 1 and the chosen maximum.

The user tries to guess the number.

The game gives hints:

If the guess is too high

If the guess is too low

The game continues until:

The user guesses the correct number, or

The user types "quit" to exit.

After winning, the player can play again.
